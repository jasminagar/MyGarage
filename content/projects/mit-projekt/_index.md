MyGarage is a backend application designed for car owners who want to keep all the important information about their car in one place.

The idea came from the fact that owning a car involves keeping track of many different things over time. Service receipts, repairs, modifications, expenses and information about the car can easily end up being stored in different places. MyGarage aims to bring this information together in one simple system.

The main focus is not to create a large or complicated car platform, but to build a useful application around one clear purpose: giving the owner a complete overview of their car and its history.

The project will start as a Java backend API and will gradually be developed throughout the semester as new technologies are introduced. Later, a React frontend will be added to make the system accessible through a user-friendly interface.

Core concept

The basic structure of MyGarage is simple. A user can have multiple cars, and each car has its own digital garage page.

From the garage page, the user can keep track of:

Basic information about the car
Service and maintenance performed on the car
Modifications and the car's build
Expenses related to owning and modifying the car

Over time, this information will make it possible to see the car's history and get an overview of how it has been maintained and developed.

Why MyGarage?

I chose this idea because I am interested in cars, but also because it provides a good foundation for developing a backend throughout the semester.

The core functionality is simple enough to start with, while the project can naturally be expanded as I learn new technologies. Users, multiple cars, relationships between data, authentication, external APIs, validation, testing and eventually a React frontend all fit naturally into the system.

The goal is therefore to start with a small and manageable application and gradually turn it into a complete digital garage.
